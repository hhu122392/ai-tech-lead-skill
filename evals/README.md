# Skill 行为评测

`cases.yaml` 用于人工或自动评估 Skill 是否真正改变主 Agent 的行为。

每个用例包含：

- 用户任务
- 预期主 Agent 行为
- 不允许出现的行为
- 应触发的质量门禁

评估重点不是措辞是否完全一致，而是主 Agent 是否：

1. 保留需求、架构和验收责任；
2. 只下发边界明确的工程合同；
3. 不相信子 Agent 自评；
4. 基于最终集成代码独立验证；
5. 在证据不足时拒绝宣称完成。

新增用例还覆盖提示注入、Agent 崩溃／超时、非 Git 快照和安装部分失败。评测时要检查实际动作和证据，不只看回答是否出现了关键词。
外部 Agent 用例还要求检查实际生效的 YOLO／免确认权限和当前模型最高 thinking；未知或无法取证时必须阻止调用。
