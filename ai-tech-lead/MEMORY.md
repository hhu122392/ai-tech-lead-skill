# 经验沉淀（Memory）

这个文件记录用本 Skill 跑真实任务时踩到的坑、被推翻的判断、验证过的做法。目的是下一次不用重新踩。

## 使用规则

- 开工前读一遍，避免重复踩坑。
- 收工时把本次新踩的坑按模板追加到「条目」区，最新的写在最上面。
- 一条一事，必须写证据：命令、输出、文件路径或行号。没有证据的猜测不写。
- 能改规则的，就去改 `SKILL.md` 或 `references/`，然后把条目标成 `已入规` 并写上改动位置。
- 同一个坑第一次出现时先留在这里；同类坑出现第二次，才升级成 `SKILL.md` 的规则——单次事故就写规则会让规则膨胀，两次才说明是系统性问题。
- 还没定论、或者还不适合写进规则的，标 `待入规`，不要装作已经解决。
- 新结论推翻旧结论时，直接改旧条目并在末尾标注修订日期。两条互相矛盾的结论不许并存。
- 不写密钥、令牌、账号和个人隐私。

## 条目模板

```text
### YYYY-MM-DD 一句话标题
- 场景：
- 原以为：
- 实际是：
- 证据：
- 代价：
- 沉淀（改了哪条规则 / 下次怎么做）：
- 状态：已入规 / 待入规
```
